# Commerce and Drops

## Purpose

This domain defines MONARQ’s product and drop mechanics, especially where purchases connect to access and identity.

## What this domain owns

- drop records
    
- product records
    
- key drops
    
- purchase-related access linkage
    
- drop availability state
    
- redemption-linked commerce logic
    

## What this domain is responsible for

This domain is responsible for the club’s commerce layer, especially jewelry drops and any access-related products that affect entry or entitlement.

## What it does not own

- user profile source of truth
    
- social activity
    
- challenge progression
    
- event attendance
    
- general teaching content
    

## Main entities

- product
    
- drop
    
- key drop
    
- redemption-linked item
    
- purchase record
    
- availability state
    

## Key relationships

This domain connects strongly to:

- Access and Gating
    
- Identity and Membership
    
- Admin and Operations
    

## Modeling note

Commerce should be modeled as a business domain, not treated as a generic storefront layer pasted on top of the app.
