# Access and Gating

## Purpose

This domain defines how a person enters MONARQ OS and what parts of the system they are allowed to access.

## What this domain owns

- invite codes
    
- access codes
    
- key redemption
    
- gating rules
    
- membership eligibility checks
    
- protected content access logic
    

## What this domain is responsible for

This domain is responsible for controlling entry and restricting experiences based on membership, entitlement, code redemption, or role. ## What it does not own

- long-term identity profile
    
- teachings content itself
    
- event content
    
- product catalog
    
- community posts
    

## Main entities

- access code
    
- invite
    
- redemption record
    
- entitlement
    
- membership gate
    
- unlock condition
    

## Key relationships

This domain connects strongly to:

- Identity and Membership
    
- Learning and Teachings
    
- Commerce and Drops
    
- Admin and Operations
    

## Modeling note

Access and Gating should stay explicit and policy-driven instead of being hidden across frontend conditions and scattered checks.
