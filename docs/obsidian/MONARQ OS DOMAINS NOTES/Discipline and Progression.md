# Discipline and Progression

## Purpose

This domain defines consistency, habits, progress, challenge tracking, XP, and level-based advancement.

## What this domain owns

- habits
    
- check-ins
    
- streaks
    
- challenges
    
- progress tracking
    
- XP
    
- rank/level progression logic
    
- leaderboard-related progression data31.jpg+2
    

## What this domain is responsible for

This domain is responsible for turning effort into visible progress inside MONARQ. It is the engine for accountability, status progression, and repeat engagement.

## What it does not own

- member profile identity
    
- community discussion
    
- teaching content itself
    
- event scheduling
    
- drop purchases
    

## Main entities

- habit
    
- check-in
    
- streak
    
- challenge
    
- challenge participation
    
- XP event
    
- level record
    
- progression milestone
    

## Key relationships

This domain connects strongly to:

- Identity and Membership
    
- Learning and Teachings
    
- Community and Social
    
- Events and Participation
    

## Modeling note

Progression logic should stay coherent here instead of being split inconsistently across community, profile, and challenge features.
