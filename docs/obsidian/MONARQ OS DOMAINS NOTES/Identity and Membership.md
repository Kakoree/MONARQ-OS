# Identity and Membership

## Purpose

This domain defines who a member is inside MONARQ OS.

## What this domain owns

- user identity
    
- profile
    
- membership state
    
- rank/status visibility
    
- member-facing account identity
    
- club presence of a user
    

## What this domain is responsible for

This domain is responsible for representing a person as a MONARQ member, including who they are, what status they hold, and how they appear to others in the system.41.jpg+1

## What it does not own

- invite redemption logic
    
- gated content rules
    
- social posts
    
- challenge progress
    
- event attendance
    
- purchase records
    

## Main entities

- user
    
- profile
    
- membership
    
- role
    
- member status
    
- rank / level reference
    

## Key relationships

This domain connects strongly to:

- Access and Gating
    
- Community and Social
    
- Discipline and Progression
    
- Admin and Operations
    

## Modeling note

A person’s identity in the system should stay cleanly separated from the many actions they take in other domains.
