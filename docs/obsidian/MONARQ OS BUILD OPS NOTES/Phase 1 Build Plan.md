# Phase 1 Build Plan

## Purpose
Defines the first actual build phase for MONARQ OS.

## Goal
Ship the first usable foundation of MONARQ OS with the correct stack, core shell, auth flow, and MVP base.

## Must be built in Phase 1
- Next.js app setup
- Vercel deployment setup
- Supabase project setup
- Auth foundation
- Basic membership/access model
- App shell and navigation
- Profile foundation
- Home / Daily OS foundation
- Initial teachings structure
- Initial challenge/progression structure

## Not in Phase 1
- Full community depth
- Advanced events system
- Full commerce flow
- AI coach
- Deep admin tools

## Order
1. Project setup
2. Database/auth setup
3. App shell
4. Core pages
5. Basic data flows
6. Preview deployment
7. QA pass

## Exit condition
Phase 1 is complete when a gated member can sign in, access the app, view the shell, use the first core pages, and the app is deployed in preview safely.
