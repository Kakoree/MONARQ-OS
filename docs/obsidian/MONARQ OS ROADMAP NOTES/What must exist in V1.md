

V1 must prove the core loop of the MONARQ club.

V1 does not need every idea. It needs the smallest complete version of the world.

The must-have V1 components are:

## Access and identity

- Code-based onboarding / gated entry
    
- Member account creation
    
- Basic profile
    
- Membership status / identity layer
    

## Home and daily rhythm

- Home dashboard
    
- Daily check-in
    
- Habit tracking
    
- Streak system
    
- Notifications
    

## Growth and teachings

- Teachings/content library
    
- Locked vs unlocked content
    
- Basic progression / level system
    

## Community

- Community feed
    
- Post wins / updates
    
- Challenge participation
    
- Basic leaderboard
    
- Member discovery
    

## Commerce and access

- Drop center
    
- Key drop explanation / redemption logic
    
- Event or live call announcements
    

## Control layer

- Admin system for content, access, and moderation
    
- Basic analytics on activity and retention
    
- Clear roles and permissions
    

V1 should answer one question:  
**Will members actually return, engage, and feel part of the MONARQ world?** MVP planning works best when the first release proves the core user loop before expanding breadth.
