

Some MONARQ OS decisions depend on others being resolved first.

Main dependencies include:

## Brand dependencies

- Final naming consistency: MONARQ vs MONARCH
    
- Voice, tone, and doctrine locked
    
- Visual direction and graphic profile confirmed
    

## Product dependencies

- Core domains defined
    
- V1 scope locked
    
- Navigation structure decided
    
- Member journey mapped
    

## Technical dependencies

- Stack decision
    
- Auth and access architecture
    
- Database structure
    
- Role and permission model
    
- Admin control model
    

## Content dependencies

- Teaching categories
    
- Challenge formats
    
- Onboarding messaging
    
- Notification tone
    
- Level / unlock logic
    

## Commerce dependencies

- How drops connect to membership
    
- How codes work
    
- What key access unlocks
    
- Whether access is permanent, tiered, or time-based
    

## Community dependencies

- Feed rules
    
- Moderation model
    
- Leaderboard logic
    
- Social status logic
    
- Anti-spam / anti-clout rules
    

This note should be updated whenever a blocked decision is discovered, because unresolved dependencies create bad prompts, misbuilt features, and expensive rework.
