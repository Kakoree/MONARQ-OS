# Teachings

## Purpose

This feature area controls the learning and knowledge system of MONARQ OS.

## Core job

Deliver structured teachings that help members grow, with content that can be unlocked over time based on level, access, or progression.

## Must include

- Teachings library
    
- Categories or paths
    
- Individual teaching pages
    
- Locked / unlocked logic
    
- Progress state

## Desired feeling

Teachings should feel valuable, curated, and earned. It should not feel like a random video dump or a bloated course platform.GOAL.jpg+1

## Non-goals for V1

- Complex LMS features
    
- Certificates
    
- Note-sharing systems
    
- Full quiz/testing engine
    
- Large-scale content editormvp+1
    

## Success looks like

Members can discover teachings, understand what is available, see what unlocks later, and continue a clear growth path.[kwiqwork](https://kwiqwork.com/blog/write-mvp-spec-developers-understand)

## Build note

Teachings must connect to progression and identity so the content feels like part of the club system, not a separate module.
