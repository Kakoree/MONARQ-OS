# Home and Daily OS

## Purpose

This is the daily command center of MONARQ OS. It should be the page members return to every day.

## Core job

Give the member one clear place to orient themselves, check in, see progress, and know what matters today.

## Must include

- Daily check-in
    
- Habit / discipline view
    
- Streak visibility
    
- Today’s priorities or routine
    
- Progress snapshot
    
- Quick access to current challenge / teachings / events
    
- Motivating but calm home experience
    

## Desired feeling

This page should feel like a personal operating system: clean, powerful, and part of daily life. It should encourage consistency, not overwhelm.

## Non-goals for V1

- Overloaded analytics dashboard
    
- Too many widgets
    
- Full life-tracking complexity
    
- Heavy customization on day 
    

## Success looks like

A member can open the app and instantly understand:

- where they stand,
    
- what to do today,
    
- and what momentum they are building.
    

## Build note

This page should become the retention anchor of the product, so clarity and repeat use matter more than feature count.
