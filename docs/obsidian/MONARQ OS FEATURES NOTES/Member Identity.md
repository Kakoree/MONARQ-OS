# Member Identity

## Purpose

This feature area defines how each member appears and is recognized inside MONARQ OS.

## Core job

Give members a clear identity in the system through profile, rank, progression, and visible club status.

## Must include

- Profile page
    
- Profile image
    
- Basic bio / identity information
    
- Rank or level
    
- Membership status
    
- Visible progress markers
    
- Public-facing member card inside the app41.jpg+1
    

## Desired feeling

Member identity should feel prestigious and intentional. It should reinforce belonging, progress, and personal presence in the club.41.jpg+1

## Non-goals for V1

- Deep profile customization
    
- Public vanity URLs
    
- Social follower economy
    
- Portfolio-style personal pagespeiko+1
    

## Success looks like

Members can recognize themselves and others as real participants in the MONARQ ecosystem, with visible status and identity.[kwiqwork](https://kwiqwork.com/blog/write-mvp-spec-developers-understand)

## Build note

This feature is important for both community and progression, so it should connect cleanly to profile, XP, rank, and membership access.
