## Purpose

This note defines the overall design direction for MONARQ OS. It is the highest-level design reference and should be used to keep the product visually consistent, premium, and structurally clear.

## Design goal

MONARQ OS should feel like a private club operating system, not a generic SaaS dashboard and not a hype brand landing page. It should feel premium, calm, cinematic, exclusive, and disciplined. The UI should support identity, progression, community, and lifestyle without becoming cluttered or visually loud

## Core principles

- Premium, not flashy.
    
- Dark, not dull.
    
- Structured, not crowded.
    
- Exclusive, not confusing.
    
- Motivating, not corny.
    
- Cinematic, not gimmicky.
    
- Lifestyle-first, commerce-second

## What the system must support

- A premium member dashboard.
    
- Community and social interactions.
    
- Teachings and content.
    
- Challenges and progression.
    
- Events and calls.
    
- Habit/discipline tracking.
    
- Member identity and rank systems.
    

## What to avoid

- Generic dark-template design.
    
- Purple/blue AI gradients.
    
- Too many colors.
    
- Overcrowded dashboard layouts.
    
- Hyper-masculine “alpha guru” aesthetics.
    
- Gold everywhere.
    

## Build rule

If a design decision does not support clarity, exclusivity, discipline, or brand identity, it should be removed. Claude Code should treat this note as the top-level visual and product design reference.
