## Visual rules

- Use restrained dark surfaces.
    
- Use gold/champagne accents sparingly.
    
- Preserve strong spacing and hierarchy.
    
- Keep typography premium but readable.
    
- Use cinematic imagery carefully.
    
- Favor calm, deliberate UI over loud visual effects.GOAL.jpg+2
    

## Structural rules

- Respect the left-rail shell.
    
- Keep navigation clear and low-clutter.
    
- Reuse component patterns.
    
- Do not introduce new layout paradigms unless needed.
    
- Keep pages consistent inside the same system.[Memory](/search/222bc957-fda1-47b0-a112-0997de1db972)
    

## Component rules

- Build reusable components first.
    
- Document states when creating important components.
    
- Prefer extending an existing component over inventing a new one.
    
- Keep cards, buttons, and tabs visually consistent.docsio+1
    

## What Claude must avoid

- Purple/blue AI gradients.
    
- Vibrant startup color palettes.
    
- Over-rounded UI.
    
- Template-looking dashboards.
    
- Overdesigned motion.
    
- Random visual experimentation outside the design notes.51.jpg+1[thisisglance](https://thisisglance.com/blog/consider-when-creating-luxury-app)
    

## Workflow rules

- Read relevant design notes before building.
    
- Keep output aligned to the current design system.
    
- When a new pattern is needed, add it intentionally instead of improvising.
    
- Prefer quality and consistency over feature sprawl.agent-layer+2
    

## Build priority

1. Establish shell and layout.
    
2. Define core tokens and typography.
    
3. Build reusable components.
    
4. Build the key pages.
    
5. Refine motion, polish, and page-specific depth.docsio+1
