

# Brand Direction

## Purpose

This note defines how MONARQ should look and feel as a brand inside the app.

## Brand feeling

MONARQ should feel:

- private,
    
- elevated,
    
- disciplined,
    
- tasteful,
    
- cinematic,
    
- aspirational,
    
- and grounded.GOAL.jpg+2
    

## Visual mood

The brand should feel like a modern private club mixed with luxury editorial and disciplined self-development. It should not feel like a crypto brand, a gym bro app, or a cheap luxury template.linkedin+2

## Color direction

- Main base: black, charcoal, deep graphite.
    
- Text: warm white, muted stone gray.
    
- Accent: muted gold / champagne.
    
- Secondary utility tones: deep olive, desaturated bronze, muted green only where needed.
    

Gold should be used as a signal, not as the whole theme.31.jpg+3

## Typography direction

Use one refined display font for major identity moments and one highly readable UI font for everything functional. The system should feel more premium and editorial than the references, while still staying practical for a real product.[linkedin](https://www.linkedin.com/pulse/building-luxury-ecommerce-apps-premium-brands-furniture-stores-yjpec)101.jpg+1

## Imagery direction

Imagery should be cinematic and identity-driven:

- mountain and landscape scenes,
    
- reflective solitary moments,
    
- premium lifestyle,
    
- training and discipline,
    
- wealth-building / work scenes,
    
- club and event atmosphere.71.jpg+4
    

## What to avoid

- Fake luxury clichés.
    
- Neon glow.
    
- Excessive gold trim.
    
- Random stock photos.
    
- Overly aggressive masculine branding.

## Build rule

Claude Code should preserve brand restraint. It should not add colors, textures, icon styles, or visual themes that are not explicitly part of this direction.
